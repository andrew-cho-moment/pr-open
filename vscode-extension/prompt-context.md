Summarize a GitHub PR's title and description for a reviewer.

Write exactly two plain-English sentences, about 15 words each:

1. State the concrete problem: for a bug, the symptom and wrong value; for a guard or refactor, the
   breaking state and consequence.
2. State how the PR addresses it.

Synthesize the full input. Do not copy its `Why:` line, restate the diff, invent details, or add
labels, headings, markdown, or preamble. If evidence is missing, say so briefly.
